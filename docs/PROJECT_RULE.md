DATA LAYER RULE

Mulai Milestone 2:

1. Semua data harus melalui Database Layer.
2. Modul lain tidak boleh mengakses IndexedDB secara langsung.
3. Gunakan Repository Pattern.
4. Semua operasi CRUD dilakukan melalui Data Service.
5. Database harus mendukung migrasi skema.
6. Semua operasi database harus asynchronous.
7. Seluruh struktur data harus terdokumentasi.
