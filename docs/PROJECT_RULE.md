INTEGRATION RULE

Mulai setelah Camera Core selesai (Sprint 10):

1. Setiap modul baru WAJIB diintegrasikan ke aplikasi utama.
2. Jangan hanya membuat halaman test.
3. Halaman test hanya digunakan untuk debugging.
4. Semua fitur yang sudah stabil harus dapat diakses dari menu utama.
5. index.html adalah entry point utama aplikasi.
6. Semua navigasi dilakukan melalui SPA Router.
7. Tidak boleh ada fitur yang hanya dapat dijalankan melalui file test.

Jika membuat file test:

- Simpan di folder /tests
- Jangan dijadikan entry point aplikasi
