
# PROJECT RULE

Project:
MeasureVision

Platform:
Project di buat dengan iphone tanpa komputer dan harus bisa di tes dengan iphone

Application:
Progressive Web App (PWA)

==================================================

DEVELOPMENT GOAL

Membangun aplikasi pengukuran dimensi benda kecil menggunakan kamera iPhone.

Prioritas utama:

1. Akurasi
2. Stabilitas
3. Modularitas
4. Kemudahan Maintenance

==================================================

TECH STACK

- HTML5
- CSS3
- Vanilla JavaScript (ES Module)
- OpenCV.js
- IndexedDB
- Service Worker

Tidak menggunakan framework.

==================================================

DEVELOPMENT RULE

- Jangan mengubah struktur folder.
- Jangan mengubah nama file.
- Jangan menghapus module lama.
- Jangan mengubah UI tanpa diminta.
- Jangan mengubah module lain kecuali benar-benar diperlukan.
- Jika harus mengubah module lain, jelaskan alasannya terlebih dahulu.

==================================================

CODING RULE

- Clean Code
- ES Module
- Reusable
- Single Responsibility
- Semua fungsi diberi komentar
- Semua error ditangani
- Tidak boleh ada duplicate code

==================================================

SPRINT RULE

Kerjakan hanya SATU Sprint.

Jangan mengerjakan Sprint berikutnya.

Berhenti setelah Sprint selesai.

==================================================

OUTPUT

Setelah selesai tampilkan:

1. Ringkasan
2. File Baru
3. File Diubah
4. Cara Test
5. Dependency
6. Catatan

==================================================

IMPORTANT

Project mengikuti PROJECT_SPEC.md.
